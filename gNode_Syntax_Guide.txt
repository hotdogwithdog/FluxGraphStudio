@inputs // Following lines Will be the inputs


@uniforms // Following lines Will be the uniforms


@outputs // Following lines Will be the outputs


@shader // Following lines Will be the shader itself (You must not put the declaration of the inputs, uniforms, outputs or size of workgroup on glsl it Will be autogenerated before give the shader code to glslang)


// Now for the inputs, you need to write the @inputs and in the following lines the format is like this
imageFormat: name // One per line


// Now for the uniforms, you need to write the @uniforms and in the following lines the format is like this
Type: name // One per line
